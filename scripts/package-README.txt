yt-dlp Right Click
==================

INSTALL
  1. Double-click Setup.cmd.
     (If Windows says "Windows protected your PC", click More info, then Run anyway.)
  2. Follow the last step it shows you in Chrome: Developer mode, Load unpacked,
     Ctrl+V, Select Folder.

That's it. Setup downloads yt-dlp, ffmpeg, and Deno if you don't have them,
and the extension fills in its own settings.

UPDATE
  Download the new version and run its Setup.cmd. Then click the reload
  arrow on the yt-dlp Right Click card in chrome://extensions.

UNINSTALL
  Double-click Uninstall.cmd, then click Remove on the extension in
  chrome://extensions. Your downloaded files are kept.

Help and source: https://github.com/biggiesmallcap-blip/yt-dlp-right-click
