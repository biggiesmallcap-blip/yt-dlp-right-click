Tools and folder

Filled in automatically by Setup. Change them only if you keep yt-dlp or ffmpeg somewhere else; a folder or the .exe itself both work.

Needed for MP4 merging and audio conversion.

Files land in Video, Audio, Files, and Instagram subfolders. Job logs older than 30 days are deleted automatically.

Check setup runs yt-dlp and ffmpeg once to confirm they work. The install folder holds the extension, the helper program, and any tools Setup downloaded.

Downloads

Cookies

Some videos need you to be signed in. yt-dlp can borrow your login cookies for those.

If set, this file is used instead of a browser. Chrome, Edge, and Brave on Windows now encrypt their cookies so yt-dlp often cannot read them; exporting a cookies.txt (Netscape format) or using Firefox is the reliable fix. Treat the file like a password.

Updates

Sites change constantly, and an old yt-dlp is the most common reason downloads break.

YouTube JavaScript runtime

YouTube needs a JavaScript runtime such as Deno or Node.js. Automatic finds an installed one.

Only for unusual installs. Pick a specific runtime above when you set this.

Developer setup

Only for building from source. Normal installs use Setup.cmd and never need this.

Run from the project folder in PowerShell after cargo build --release.
